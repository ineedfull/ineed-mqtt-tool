# MQTT 字体规范

Electron 与 Tauri 使用同一套工作台样式。字号集中在 `packages/workbench/src/styles/typography.css`，与 LinkLab 对齐。

| 用途 | CSS 变量 | 普通模式 | 大字模式 |
| --- | --- | --- | --- |
| 时间、状态、辅助说明 | `--font-size-small` | 11px | 12px |
| 页签、表头、按钮、表单 | `--font-size-control` | 12px | 13px |
| 正文、连接名称、日志和历史记录 | `--font-size` | 13px | 14px |
| 品牌栏、当前连接标题 | `--font-size-heading` | 14px | 15px |
| 弹窗标题 | `--font-size-title` | 15px | 16px |
| 关于页产品名称 | `--font-size-display` | 20px | 21px |
| 消息原文、发送编辑器、详情内容 | `--font-size-code` | 13px | 16px |

- 在组件中使用语义变量，避免写死字号或继续使用 `--font-scale` 倍乘。
- `.mqtt-app` 和 `.history-page` 根据已保存的 `largeFont` 设置切换 `large-font` 类。历史窗口重新获得焦点时刷新设置；读取失败时保留上次字号，不影响历史查询。
- `base.css` 位于 `legacy` 层，新版 `desktop.css` 在层外。两者均引用同一组变量，避免旧大字选择器被新版固定字号覆盖。
- HEX、主题、时间和原始消息可保留等宽字体；同类信息采用相同字号。关于页共用布局的字体映射也集中在 `typography.css`。
- 验证普通/大字模式下的工作台、连接及订阅弹窗、设置、关于、消息/日志历史，以及 1440×900、1120×720、960×600 三个尺寸。

## 工作台布局

- 工作台按「连接列表 → 当前连接的订阅 → 消息/日志」排列。折叠连接列表不隐藏订阅列，切换连接时同步更新订阅。
- 订阅栏默认 260px，可拖动右边界调整并自动记住宽度；键盘方向键微调，Home 恢复默认宽度，End 调至当前窗口允许的最大宽度。窗口变窄时给消息区预留空间。
- 点击订阅条目的主题、格式、QoS、颜色标记或留白均可切换筛选；复制和更多按钮独立处理，不触发筛选。再次点击当前订阅可取消筛选；主题最多展示两行，悬停查看完整内容。第二行以轻量文字显示格式、QoS 和消息数，右侧保留复制与更多按钮。更多菜单提供复制到连接、取消订阅，支持方向键、Escape、外部点击和焦点返回。
- 选中订阅使用淡色背景，保留主题颜色标记与带状态说明的小圆点。设置与关于在连接列表底部靠左排列，收起时仅显示居中图标。
- 实时消息采用聊天气泡：接收靠左、发送靠右，显示主题、时间、QoS、保留标记及字节数。内容保留换行，点击气泡查看详情，复制按钮复制完整内容；超长预览提示截断。
- 订阅列表与消息列表独立滚动；窄窗口收窄订阅列，消息编辑器工具栏按需换行。

## 发送区

- 按「主题与 QoS/Retain → 编辑工具 → 内容编辑器 → 状态与发送」排列；编辑工具左侧选择 JSON/Text 与格式化，右侧选择发送方式并复制内容。
- 编辑器使用统一细边框，保留行号、语法高亮和无效 JSON 提示。默认高度 220px，继续保存用户拖动的高度；内容区使用代码字号。
- 底部左侧显示 UTF-8 字节数、JSON 校验和复制反馈，右侧放连接提示、定时发送和发送按钮。窄内容区隐藏快捷键提示，工具分组按需换行。
- 定时设置在按钮上方展开，不挤占工具栏；运行时显示倒计时和停止操作。复制、手动发送、Ctrl/⌘+Enter 和定时发送共用原有功能逻辑。
- HEX 沿用原有语义：把输入文本转换为 UTF-8 字节发送，并显示/复制十六进制预览；**不把输入的十六进制字符串解码成原始字节**。字节预览单独成行，避免挤压编辑工具。

专项回归：

```sh
npx playwright test -c packages/workbench/playwright.typography.config.js
```

该配置分别启动 Electron 和 Tauri 渲染入口，在 Chromium、WebKit 中验证独立订阅列、聊天消息、发送与定时操作、编辑区高度记忆，测量实际字号并生成截图；使用预览适配器，不连接真实 MQTT Broker。

时间及毫秒的统一格式、紧凑显示与历史兼容见[界面时间显示](date-time-display.md)。
