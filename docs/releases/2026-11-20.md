# MQTT Tool 0.1.1 测试版

发布日期：2026-11-20。

## 本版调整

- 完善订阅生命周期、历史落盘与断连边界，整理工作台及更新模块，提高维护可读性。
- 保留每条订阅独立选择 JSON / Text / HEX 的使用方式，补充本机 Broker 与三种格式的[快速上手](../quick-start.md)。
- 补齐公开仓库导航、使用说明与反馈入口。

## 安装与验证范围

从[官网下载页](https://mqtt.ineedfull.com/downloads/)选择系统、CPU 架构及运行时，按页面列出的文件和构建标识下载。Electron 自带 Chromium，通常占用更多内存与磁盘。构建命令与矩阵见[打包指南](../desktop-packaging.md)。

本版按测试安装包分发，未配置 macOS Developer ID / 公证或 Windows Authenticode 正式签名。Windows Electron 包使用 Linux/Wine 交叉构建；生成文件不代表 Windows/Linux/macOS Intel 已全部通过实机安装升级验收。本批实际构建、摘要与运行检查以发布交接记录为准。

安装前退出应用，保留原应用身份和数据目录；完整备份先退出后复制用户数据目录。场景导出与消息历史不是同一种备份。本批不发布自动更新 feed，手工安装包不替代[更新签名要求](../in-app-updates.md)。
