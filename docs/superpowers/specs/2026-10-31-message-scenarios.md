# 设备消息场景测试

已批准的业务方向：保存订阅响应、发布指令、关联 JSON 请求 ID、检查业务字段并交接原始证据。Electron/Tauri 共用领域和界面，不改变 SQLite schema、应用 ID、原连接和历史记录。

## 设计

新增「场景测试」工作区页签：左侧选择已有场景，表单编辑名称、版本、发布/响应主题、JSON 载荷模板、变量 JSON、关联字段路径、超时和多条 equals/type/range 断言。提供新建、保存、删除、JSON 导入预览/确认、导出和结果导出。导出展示完整 JSON 并调用原生剪贴板，Electron 另提供文件下载；Tauri 首版不提供原生另存为文件。选择当前实时连接执行，一次仅一个场景。模板使用 {{variable}} 与保留的 {{requestId}}，JSON 字符串内替换时正确转义；请求 JSON 由关联路径强制写入唯一 ID，响应以同一路径作严格字符串比较。路径仅允许简单点分隔字段/数组数字下标，禁止原型字段和脚本。

固定的具体响应主题（不支持通配符）复用当前连接。生命周期模块在既有连接订阅队列内持有临时订阅，等待真实 SUBACK 后发布，直到报告终态后才清理；期间该连接的订阅编辑排队。若已有同名订阅，按原 QoS 借用并保留；新增临时订阅先记入既有持久清理队列，再发送 SUBSCRIBE，正常结束 UNSUBSCRIBE 后清除意图，断连/重启后由原清理机制重试，保护用户同名订阅。重连/手动断连及关闭使本轮失效。停止可立即终止报告，迟到 ACK 不能发布。

报告状态 pass/fail/timeout/stopped/connection-loss，保存唯一 run/request ID、连接 ID/名称（无地址/用户名/密码）、版本化场景快照、解析后的请求、收到的原文/时间、匹配与忽略原因、断言和清理错误。超时覆盖排队/订阅/发布/等待，QoS ACK 不是业务成功；有效响应可以先于 PUBACK。终态冻结，重复、迟到、retained、其他连接和其他请求 ID 不会改变结果；无效 JSON 记录并继续等待。所有证据有界（64条，单条64KiB，超大响应不参与通过判定），证据原始载荷累计256KiB，报告最多保留30份/16MiB，场景最多100个/2MiB；存储错误明确展示，不假装保存成功。

## 取舍

选择现有 settings 表而非新表，沿用双端 saveSetting/getAll 以兼容升级。选择声明式 JSON 表单而非执行任意脚本。具体响应主题允许固定主题和请求级唯一主题，首版不实现 MQTT 5 属性、历史回放、心跳或 Will。报告/模板仅导出白名单字段；用户自行输入的业务载荷/变量仍会包含在导出中。

## 验收

先失败后实现：模型导入/变量/安全路径/断言；运行器 SUBACK 顺序、同步响应、QoS ACK 不算通过、retain/错 ID/错连接/重复/迟到、停止前后、断连/重连；生命周期保存订阅保护和迟到 ACK 清理；持久化失败与导入预览。实际本地 broker 设备通过/失败/超时/停止。共享组件及两个 renderer 浅深色/普通大字/折叠/窄窗，lint 和双 renderer 构建。浏览器/原生服务和安装包验证分别记录。
